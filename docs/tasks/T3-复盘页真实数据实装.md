# T3 任务书：复盘页真实数据实装（M1，前端 W4 + 后端联调）

> 用户要求：胜率曲线、关键手、一选分析等实装（项目书 M0/M1 要求）。数据链路后端已就绪，本任务把前端从"仅 mock"提升为"真实后端数据 + 优雅降级"。

## ① 做什么

在 `frontend/index.html` + `frontend/js/app.js` 上实现（M0 骨架保留）：

1. **真实复盘数据流**（数据源=真实后端时）：
   - `loadSgf()` 后：`POST /api/v1/review/analyze`（body `{sgf_text, profile:"fast"}`）→ 得 `review_id`；
   - 轮询 `GET /api/v1/review/{id}/status`（1.5s 间隔）：`progress` 显示进度条（复用 `.progress-*` 样式）；status=done 后取 `GET /api/v1/review/{id}` 详情；failed 显示 error；
   - 详情结构（契约 §4.1）：`moves[]`（move_number/color/coord/winrate/score_lead/visits/category/delta/best_coord/pv）+ `stats`。**先读 `docs/architecture.md` §4.1 与 `backend/common/models.py` 的 `ReviewDetailResponse`/`MoveInfo` 确认字段名，以代码为准**。
2. **胜率曲线（真实数据）**：以每手 `winrate`（当前方视角）画折线；关键手按 `category` 用红/黄/绿点标注（blunder/question/good）；随播放联动当前手高亮。canvas 自绘（曲线非棋盘，允许）。
3. **关键手列表（真实数据）**：`category !== 'normal'` 的手：第 N 手 + 类别 + 坐标 + `推荐 {best_coord}`；点击定位（沿用 `goToMove`）。
4. **棋盘一选标记（WGo 官方能力）**：当前手数据存在时，在棋盘上显示：
   - 一选点 `best_coord` 圆点标记（用 `WGo.Board` 的 `addObject`，如坐标 A/B/C 标记字母或圆圈——参考 WGo 官方示例 `markup` 用法，**禁止手写坐标换算**，坐标直接从后端字段或 WGo Kifu 节点读）；
   - 落点本身标记（如三角形 `MA`）；
   - 切换手数时移除旧标记再添加新标记。
5. **讲解面板**：关键手列表项/棋盘手数点击后，面板显示该手：一选/PV 文字 + 「AI 讲解」按钮 → `POST /api/v1/coach/explain`（`{review_id, move_number}`）。**M2 前 LLM 讲解可能未就绪**：请求失败或返回占位时显示降级提示（如"讲解生成中/暂不可用（M2）"），**禁止页面崩溃、禁止真实烧钱循环重试**（最多 1 次调用）。mock 模式下用本地 mock 讲解文本。
6. **设置面板接真实 T0 数据**：`getSystemInfo/getHealth/getVersion` 拉真实版本/引擎后端/schema；引擎后端下拉（opencl/cpu/auto）可操作 → `updateSettings`；「清缓存」按钮 → `clearCache`；失败 toast 提示。
7. **WS 进度（可选加分）**：`frontend/js/ws.js` 已有封装，若稳定可替代轮询；不稳定就保留轮询。

## ② 禁止做什么

- **禁止自写棋盘/坐标换算/落子/提子/变化播放**（一选标记也走 `WGo.Board.addObject`，坐标来自后端字段或 WGo 节点）；
- 禁止真实调用 DeepSeek 烧钱（explain 最多单次调用，失败静默降级；本轮迭代禁止 max_tokens>400 的调用）；
- 禁止改后端契约字段（只读使用）；禁止破坏 M0 已验收功能（mock 模式照常工作）；
- 禁止引入构建工具/Node。

## ③ 验收方式

1. 启动后端（项目根 `.\.venv\Scripts\python.exe -m uvicorn backend.main:app --port 8765`），浏览器打开 `http://127.0.0.1:8765/`，数据源=真实后端：
   - 载入 9 路示例 → 分析进度条出现 → done 后胜率曲线为真实数据（20 个点）、关键手列表与 mock 的三档一致（7 疑问/12 坏/17 好，允许引擎判定差异，但列表非空）；
   - 点击关键手 → 棋盘显示一选点标记 + 落点标记，讲解面板出现；
   - 数据源切回 Mock → 行为与 M0 一致。
2. Playwright 更新 `scripts/playwright_m0.py`（或新增 `playwright_m1.py`）：真实后端模式全流程截图 ≥ 4 张（分析中进度 / 曲线真实数据 / 关键手定位+棋盘标记 / 讲解面板），存 `docs/tasks/evidence/`。
3. 后端测试不受影响（`.\.venv\Scripts\python.exe -m unittest discover -s tests` 原数量全绿——本任务不改后端，仅联调确认）。
4. 红线自检：新增代码无手写坐标换算（grep getX/getY/coordToSgf）。
